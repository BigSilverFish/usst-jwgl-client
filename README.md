## 🌟 核心特性

### 🧪 实验课表导入
- 课表页点击右上角 **＋ → 导入实验课表**，选择预约 Excel 文件。
- 检查页自动修复 XLSX 文件头 BOM、校验工作簿，并展示预约预览；确认后才写入默认课表。
- 再次导入只替换由此功能导入的实验预约，不影响普通课程；源文件不会被修改。
- 优先使用 `.xlsx`。二进制旧版 `.xls` 请先在 Excel/WPS 中另存为 `.xlsx`。详见 [`LAB-IMPORT.md`](LAB-IMPORT.md)。

### 🔍 全校课表与蹭课助手（v1.1.2 持续升级）
- **本地持久缓存与手动同步**：
  - 全校课表与空教室查询支持 **SharedPreferences + 内存二级持久缓存**，首次检索后秒开历史排课数据，并在副标题实时标注缓存状态（如 `缓存 · 刚刚更新`）；
  - 右上角常驻手动同步刷新按键 🔄，支持随时拉取最新排课数据（仅在手动同步失败时弹出 Toast 提示检查无线校园网连接）。
- **当前时段智能推荐**：
  - 工作日（07:00-20:15）默认展示当前时段正在上/即将开始上的课程，且**仅显示本周有排课的教学班**；
  - 非上课时段或周末默认置空并展示温馨提示，引导主动检索，界面清爽无干扰。
- **全方位多维筛选项**：
  - 支持按**时段**精确检索：1-2节（08:00-09:25）、3-5节（09:45-11:55）、6-7节（13:00-14:25）、8-10节（14:45-16:55）、11-13节（18:00-20:15）；
  - 支持按学期（含本学期与未来跨学期排课预测）、周次（1~20周）、星期（周一~周日）、开课学院及教师关键词组合查询。
- **本研课程智能解析与合并**：
  - 智能合并研究生连堂节次（如原拆散的“第3节”“第4节”“第5节”自动合并规范展示为“第3-5节”）；
  - 单双周思政类等历史课程智能识别：“1-15周（单周）”、“2-16周（双周）”；仅显示学分，取消冗余学时显示；
  - 支持从班级号一键提取课程代码，直通教务官方课程大纲与课程分类。
- **官方全校排课网页版快速直达**：
  - 全校课表页右上角刷新按钮旁常驻地球图标 🌐，一键免密拉起全校排课轻应用网页版，查看全校可视化完整课表。

### 🏛️ 空教室自习室反向查询（支持本地缓存）
  - 复用全校课表二级缓存，离线或非校园网环境下也可直接查阅已缓存的空教室数据，右上角支持一键手动刷新；
  - “仅空闲”开关关闭时，全校已知教室（一教、三教、四教、卓越楼、国合楼、综合楼等）**严格按教室编号从小到大升序连续呈现**，空闲与已占用教室清晰穿插；
  - 统计数字（“空闲 X / 共 Y 间”）仅在主动点击“查询空教室”或手动刷新后采用轻量 Toast 瞬时弹出提醒。

### 🎨 现代化沉浸式 UI、双导航模式与平板横屏适配
- **手机端侧栏 / 底栏双导航模式自由切换**：
  - **侧栏模式**：支持左滑呼出抽屉，并新增**双击课表空白处呼出侧栏**快捷手势（可在个人设置中自由开关）；
  - **底栏模式**：提供底部常驻四栏导航（**课程表 · 成绩查询 · 更多功能 · 个人设置**），将全校查课、空教室查询、考试日程、成绩单证明与官方系统直通车统一收纳进「更多功能」聚合页。
- **平板 / 折叠屏横屏（Pad 模式）深度适配**：
  - 在大屏横屏（`sw600dp-land`）下自动切换为左侧常驻导航栏 + 右侧多列网格/主从双栏布局（成绩查询左总览右明细、全校查课双列、空教室三列、个人设置双栏并排）。
- **全屏沉浸与单行紧凑顶栏**：
  - 课程表与成绩查询顶栏的学年与学期合并为单行紧凑显示（如 `2026-2027学年 第1学期`）；
  - 采用 Edge-to-Edge 视觉设计，全透明沉浸式状态栏与全面屏手势条无缝融合，自动适配深色（Dark Mode）与浅色（Light Mode）模式。
- **成绩查询页一体化连贯划动**：
  - 将“学业成绩总览”综合统计卡片与详细成绩列表合二为一，支持整体连贯平滑划动；
  - 精确收窄底部留白，精准避让全面屏手势横条。

### 📅 智能课表系统
- **时刻表双轨支持**：
  - 自动识别新老学期制度：2025-2026-2 及以往采用 **12节老时刻表**，2026-2027-1 起采用 **13节新时刻表**；
  - 每日首次启动自动云端拉取学期与放假调休信息，保障教学周次准确。
  - 左侧时刻栏清晰呈现每小节课程准确的上课与下课时间，支持时段视觉分隔元素（上午 / 下午 / 晚上）。
- **全学期周次视图**：
  - 顶部胶囊一键调起周次选择弹窗，当前周次高亮标记，日期（月/日）动态匹配；
  - 支持“仅本周课程”单选过滤，支持多周次/单双周排课课程合并与冲突检测。
- **自定义排课与调度**：
  - 支持自定义新增课程并智能校验节次冲突；
  - 支持**本周单次停课**、**单时段删除**与**整门课程移除**。

### 📝 考试日程与倒计时
- 直接向教务系统请求期末、期中、缓考及补考真实日程（已彻底清除测试数据）；
- 考试周自动排布为三场次标准时间（09:00-11:00 / 13:00-15:00 / 15:30-17:30）；
- 考试前自动进行本地定时提醒。

### ⏰ 精准通知提醒
- **课前 / 考前双重独立提醒**：
  - 基于 Android 系统底层 AlarmManager 精准定时唤醒，**无需后台常驻进程，零耗电**；
  - 提醒提前量自由可调（课前可设 5~30 分钟，考前可设 15~120 分钟）；
  - 支持设备重启自动重新注册闹钟（已获安全权限保护）。

### 📊 学业情况与成绩档案
- **学业情况总览**：
  - 支持全部学期与分学期动态筛选，实时核算加权平均分与平均学分绩点 (GPA)；
  - 放宽网络超时阈值至 40 秒，彻底解决教务大数据量响应偶发超时问题。
- **学业证明与成绩单离线生成与下载**：
  - 支持生成并导出中文/英文加权平均分证明、排名证明 PDF 文档；
  - 支持一键调起系统应用查看或分享生成的正式 PDF。

### 🌐 官方教务系统免密直达
- 侧栏与「更多功能」中内置 **官方教务系统 (jwgl)** 与 **学工系统小程序 (new2017)** 直通车；
- 自动将当前登录的 CAS SSO 会话凭据无缝注入原生 WebView，实现**免输账号密码秒进教务系统后台**。

## 🔒 安全性与隐私合规

本项目经过深度安全加固，全力守护学生个人凭据与数据安全：

| 安全项 | 实现方式 |
| :--- | :--- |
| **密码存储** | 采用 Google Jetpack EncryptedSharedPreferences + Android Keystore 硬件级 AES-256 加密，密钥集异常时自动重建或退回纯内存易失存储，彻底杜绝明文凭据落盘。 |
| **网络通信** | 全面禁止明文 HTTP 流量，严格配置 `network_security_config.xml`，仅信任官方 HTTPS 通信，自动升级校内重定向链接。 |
| **WebView 隔离** | 严禁向网页注入账号密码脚本，禁用第三方 Cookie 与混合内容，严格校验 `*.usst.edu.cn` HTTPS 域名白名单并按源域隔离 Cookie。 |
| **日志脱敏** | 全面剥离 CAS 令牌、Cookie 值与个人信息日志，Release 构建通过 R8 自动移除全部调试日志。 |
| **防数据备份泄露** | 禁用 allowBackup，配置 data_extraction_rules.xml，排除一切缓存与本地 SQLite 数据库被外部提取。 |
| **广播导出防护** | 开机重启 Receiver 绑定 RECEIVE_BOOT_COMPLETED 系统级权限，阻止第三方 App 恶意唤起。 |
| **存储暴露收窄** | FileProvider 路径严格收缩在私有下载目录，杜绝全目录遍历风险。 |
| **独立私钥签名** | Release 构建采用独立 2048 位 RSA 私钥签名（SHA384withRSA），保障分发完整性与升级安全。 |
| **隐私承诺** | **本 App 为非官方开源项目，仅供开发学习交流，不收集、不上传任何隐私数据。所有数据均保存在用户手机本地。** |

## ⚡ 性能优化

- **SQLite 批量事务包裹**：课表与时段初始化批量操作全部包裹在单次 `db.beginTransaction()` 事务中，冷启动性能提升 5~10 倍。
- **UI 主线程零阻塞**：所有数据库读写、周次计算与网络会话解析均运行于 Kotlin Coroutine `Dispatchers.IO`。
- **R8 极致瘦身与混淆**：开启 Release 构建 R8 混淆、无用代码剥离与未引用资源缩减，安装包体积由 9.4MB 锐减至 **2.7MB**。
- **增量构建支持**：开启 Gradle 并行编译与构建缓存。

## 🛠️ 技术栈

- **开发语言**：Kotlin 2.0+
- **目标平台**：Android 7.0+ (API Level 24 ~ 36)
- **UI 框架**：Material Design 3 (Material Components for Android) + ViewBinding + BlurView
- **架构组件**：Lifecycle, Coroutines, Navigation, Splashscreen
- **网络与解析**：OkHttp 4.12, Jsoup 1.17, Gson 2.10
- **安全组件**：AndroidX Security Crypto (AES-256 SIV/GCM)
- **PDF 处理**：Android 原生 PdfDocument 渲染引擎
