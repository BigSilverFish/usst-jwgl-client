## 🌟 核心特性

### 🧪 实验课表智能导入与自动修复（已合并分支 `feat/lab-excel-import`）
- **多格式支持与容错解析**：
  - 打开应用课表页，点击右上角 **＋ → 导入实验课表**，即可从手机文件管理器选取预约导出文件；
  - 完美支持标准 `.xlsx` 工作簿，并向下兼容实验系统导出的 `.csv`、HTML 结构表格及旧版文本格式（扩展名为 `.xls` 的文本表）。
- **内置文件自动修复引擎**：
  - **自动剔除 UTF-8 BOM 标头**：解决部分系统导出时包含非法 BOM 字符导致的打开失败；
  - **工作簿 XML 结构校验与修复**：自动校正缺失的 Sheet 索引或畸形 XML 节点；
  - **智能清洗与去重**：自动忽略空白行与无效注释，识别同一实验时段内可能产生的重复预约并自动去重合并；
  - **绝不篡改原文件**：所有检查与修复均在临时工作副本中进行，源文件哈希与内容保持绝对不变，同时支持将修复后的规范副本另存为新文件。
- **校历与作息智能对齐**：
  - 自动依据当前学期起始周与标准作息时间（适配上理 13 节新时刻表与 12 节老时刻表），将实验的公历日期、具体时间折算为标准教学周次、星期与节次范围。
- **独立隔离存储与隐私保障**：
  - 导入前提供清晰的预约明细、空行及重复条目统计预览，用户核对后在二次确认窗口点击导入才会写入本地数据库；
  - 预约数据存入独立的 `lab_reservation` 数据表，再次导入只覆盖更新实验预约，**绝不影响普通教务排课和自定义课程**；
  - 解析全程在设备本地离线完成，不向任何第三方服务器上传任何文档与凭证。
  - 详细技术解析与操作说明详见 [`LAB-IMPORT.md`](LAB-IMPORT.md)。

### ⚡ 全校课表与全量离线缓存系统（v1.1.3 全面重构）
- **首次全量加载与磁盘持久化**：
  - 全面升级排课数据架构，首次查询时全量拉取全校 9000+ 门排课数据并固化到本地磁盘 JSON 文件与内存二级缓存；
  - **真正脱网可用**：无论是身处校外、非校园网还是弱网环境，均可秒开秒查全校各学院课程安排，告别反复加载转圈与校园网限制。
- **纯内存毫秒级联合过滤**：
  - 筛选机制全面移至纯内存计算，结合学期、学院、时段、星期、周次及教师/课程关键词的多维检索耗时**小于 2ms**，体验极为丝滑顺畅。
- **当前时段智能推荐**：
  - 工作日（07:00-20:15）默认展示当前时段正在上/即将开始上的课程，且**仅显示本周有排课的教学班**；
  - 非上课时段或周末默认置空并展示温馨提示，界面清爽无干扰。
- **全方位多维筛选项**：
  - 精确时段检索：1-2节（08:00-09:25）、3-5节（09:45-11:55）、6-7节（13:00-14:25）、8-10节（14:45-16:55）、11-13节（18:00-20:15）；
  - 支持按本学期与跨学期预测、周次（1~20周）、星期、开课学院及教师关键词灵活组合。
- **本研课程智能解析与合并**：
  - 智能合并研究生连堂节次（如原拆散的“第3节”“第4节”“第5节”自动合并规范展示为“第3-5节”）；
  - 单双周思政类等历史课程智能识别：“1-15周（单周）”、“2-16周（双周）”；仅显示学分，取消冗余学时显示；
  - 支持从班级号一键提取课程代码，直通教务官方课程大纲与课程分类。
- **手动增量同步与网页版直达**：
  - 右上角常驻手动同步按键 🔄，校园网环境下随时一键拉取最新排课变动；

## 🔒 安全性与隐私合规

本项目经过深度安全加固，全力守护学生个人凭据与数据安全：

| 安全项 | 实现方式 |
| :--- | :--- |
| **密码存储** | 采用 Google Jetpack EncryptedSharedPreferences + Android Keystore 硬件级 AES-256 加密，密钥集异常时自动重建或退回纯内存易失存储，彻底杜绝明文凭据落盘。 |
| **网络通信** | 全面禁止明文 HTTP 流量，严格配置 `network_security_config.xml`，仅信任官方 HTTPS 通信，自动升级校内重定向链接。 |
| **WebView 隔离** | 严禁向网页注入账号密码脚本，禁用第三方 Cookie 与混合内容，严格校验 `*.usst.edu.cn` HTTPS 域名白名单并按源域隔离 Cookie。 |
| **日志脱敏** | 全面剥离 CAS 令牌、Cookie 值与个人信息日志，Release 构建通过 R8 自动移除全部调试日志。 |
| **防数据备份泄露** | 禁用 allowBackup，配置 data_extraction_rules.xml，排除一切缓存与本地 SQLite 数据库被外部提取。 |
| **广播导出防护** | 开机重启 Receiver 绑定 RECEIVE_BOOT_COMPLETED 系统级权限，阻止第三方 App 恶意唤起。 |
| **存储暴露收窄** | FileProvider 路径严格收缩在私有下载目录，杜绝全目录遍历风险。 |
| **独立私钥签名** | Release 构建采用独立 2048 位 RSA 私钥签名（SHA384withRSA），保障分发完整性与升级安全。 |
| **隐私承诺** | **本 App 为非官方开源项目，仅供开发学习交流，不收集、不上传任何隐私数据。所有数据均保存在用户手机本地。** |

## ⚡ 性能优化

- **全量排课两级持久缓存**：全校课表与空教室改为首次全量加载（9000+门课程）与磁盘 JSON/内存缓存，查询时间降至 2ms 以下。
- **SQLite 批量事务包裹**：课表与时段初始化批量操作全部包裹在单次 `db.beginTransaction()` 事务中，冷启动性能提升 5~10 倍。
- **UI 主线程零阻塞**：所有数据库读写、周次计算与网络会话解析均运行于 Kotlin Coroutine `Dispatchers.IO`。
- **R8 极致瘦身与混淆**：开启 Release 构建 R8 混淆、无用代码剥离与未引用资源缩减，安装包体积由 9.4MB 锐减至 **2.7MB**。
- **增量构建支持**：开启 Gradle 并行编译与构建缓存。
