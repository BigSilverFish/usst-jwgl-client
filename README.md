## 📖 项目简介

**usst-jwgl-client** 是一个面向上海理工大学师生的第三方 Android 原生客户端，使用 Kotlin 与 Material Design 3 组件构建，直接对接学校教务系统、统一身份认证（CAS）SSO、一网畅学（TronClass）及超星学习通接口，提供课表管理、成绩与学分查询、课程学习门户、空教室检索与桌面微件等常用功能。

所有网络请求与数据存储均在本地设备完成，应用本身不设外部中转服务器。

## ✨ 主要功能

### 1. 课程门户（一网畅学 + 超星学习通）
- **双平台聚合与切换**：支持同时接入一网畅学（TronClass）与超星学习通，可通过顶栏按钮在「纯畅课」与「双平台」模式间切换；支持孤立课程手动绑定、解绑与学期归类。
- **原生课程详情**：在一个界面内集中查看待办作业、课程公告、章节课件、测验考试、课堂讨论（`forum`）与班级成员列表。
- **作业与测验支持**：
  - 支持在原生页面查看题目要求、一键复制题干，支持拍照上传或选择本地文件作为作业附件；重新提交时自动处理撤回与再次提交。
  - 支持超星客观题原生答题、学习通网盘附件上传与成绩/评语解析。
  - 内置基于 Android `PdfRenderer` 的原生 PDF 阅读器，支持常见文档预览与附件下载。
- **课堂签到与提醒**：
  - 支持畅课（扫码、数字口令、GPS/雷达定位、自主签到）及超星（二维码、手势、拍照、位置选点）多种签到方式，基于 Google ML Kit + CameraX 实现离线扫码。
  - 内置教学楼基准坐标与自动吸附逻辑，支持免无障碍权限的课堂签到提醒与通知直达。
- **作业截止提醒 (DDL Guard)**：支持 24 小时前与临期 1~3 小时两级提醒配置，通过 `WorkManager` 与 `AlarmManager` 在后台调度唤醒。

### 2. 智能课表与日程管理
- **新老作息表自动适配**：按学期自动切换 12 节旧作息表（2025-2026-2 及之前）与 13 节新作息表（2026-2027-1 起），每日同步校历开学日期与放假调休安排。
- **多周次与冲突处理**：支持周次切换、仅看本周课程筛选、重叠冲突课程并排显示；支持手动添加临时课程、单次停课及**课程锁定**（同步教务课表时保留锁定课程）。
- **实验课表导入**：支持导入教务/实验系统导出的 `.xlsx`、`.csv`、HTML 表格及 `.xls` 文本表，自动处理 UTF-8 BOM 头、日期换算周次节次与重复时段合并，并与教务课表数据隔离存储。
- **课表与学习进度联动**：点击课程详情可同步展示对应的课程门户学习进度与最近截止待办，并支持跳转课程直播/点播回放页面。

### 3. 全校课表与空教室查询
- **全校课表离线检索**：首次拉取后持久化至本地 JSON 与内存缓存，支持按学期、培养层次（本科生/研究生）、学院、时段、星期、周次、教师及课程名进行离线组合筛选，并可将任意教学班加入个人课表。
- **空教室排查**：覆盖校内 9 大主要教学楼共 396 间常规教室（一教、三教、四教、卓越楼、国合楼、综合楼、博学楼、乐学楼、勤学楼），依据当前教学周实际排课判定占用，并对常见教学楼别名做归一化处理。

### 4. 学业成绩与学分节点
- **成绩与绩点统计**：支持按全部或指定学期查看课程成绩，计算加权平均分与 GPA（自动对重修、补考课程去重）。
- **学分节点视图**：支持在学期视图与学分节点层级树间切换（平板横屏支持左右双栏独立滚动与学分进度条展示），支持替代课程状态标记。
- **排名解析与报表导出**：内置无外部依赖的 CID-CMap PDF 字符流解码器，用于解析教务系统导出的班级/专业/年级排名文件，并支持生成和分享本地成绩报表 PDF。

### 5. 桌面微件（AppWidget）
- 提供**今日课表**与 **2×2 下一节课倒计时**两种桌面微件，支持在微件内直接翻页查看日期、跳转一键签到及显示待交作业提示。
- 提供微件外观自定义与双形态实时预览页面，支持调整颜色风格（自动/浅色/深色/透明）、卡片透明度及展示字段过滤。

### 6. 账号认证与官方系统直通
- **登录与防验证码通道**：原生直连 CAS 统一身份认证；当触发图片验证码或滑块风控时，可切换至内置官方 SSO 网页登录并自动预填账密、同步 Cookie 至原生客户端。
- **官方系统直通车**：内置教务系统（`jwgl`）、学工一体化（`new2017`）与课程直播/点播（`live`）入口，通过通用 CAS SSO 预认证实现免重复登录跳转，并适配全面屏状态栏安全边距。
- **多账号隔离**：按学号独立隔离课表数据库、本地缓存与畅课设备标识，切换账号时自动刷新各平台会话。

## 🔒 安全与隐私说明

| 模块 | 实现方式 |
| :--- | :--- |
| **本地凭据加密** | 使用 Jetpack `EncryptedSharedPreferences` + Android Keystore（AES-256 SIV/GCM）加密存储账号与会话凭据；退出登录时清理本地凭据与业务缓存。 |
| **网络传输限制** | 默认禁止明文 HTTP（`cleartextTrafficPermitted="false"`），仅对尚未启用 HTTPS 的 `*.usst.edu.cn` 校内历史域名保留白名单；OkHttp 拦截器校验目标域名白名单，防止会话凭证外泄。 |
| **CAS SSO 校验** | 限制官方认证域名（`ids6.usst.edu.cn`、`ids6-443.webvpn.usst.edu.cn`）与 `/authserver/login` 路径前缀，拦截异常跳转。 |
| **WebView 与存储隔离** | Release 构建关闭 WebView 调试并禁用混合内容；`FileProvider` 仅暴露下载、上传暂存与报表等私有子目录，禁用系统自动备份（`allowBackup="false"`）。 |
| **纯本地运行** | 本项目为开源学习工具，不收集、不上传任何个人数据至第三方或开发者服务器。 |

## 🛠️ 技术栈

- **语言与并发**：Kotlin 2.0+、Kotlin Coroutines
- **平台兼容**：Android 7.0+（API 24 ~ 36），`arm64-v8a`
- **UI 组件**：Material Design 3、ViewBinding、CoordinatorLayout、BlurView
- **系统调度**：Jetpack Lifecycle、WorkManager、AlarmManager
- **网络与解析**：OkHttp 4.12、Jsoup 1.17、Gson 2.10
- **扫码与文档**：Google ML Kit Barcode Scanning、CameraX 1.3.4、Android `PdfRenderer` + 自研 CID-CMap 解码器
- **安全存储**：AndroidX Security Crypto
