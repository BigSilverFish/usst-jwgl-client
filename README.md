## 📖 项目简介

**usst-jwgl-client** 是一款彻底脱离粗糙 Web 壳、采用 100% Android 原生组件打造的第三方教务与一网畅学（TronClass）综合客户端。

针对上海理工大学现行教务系统、统一身份认证 (CAS) SSO 以及一网畅学平台，本项目深度整合了**智能双轨时刻表课表**、**一网畅学原生二级详情与极速刷课/作业提交**、**实验课表智能修复导入**、**全校课表全量离线毫秒级检索**、**9 大教学楼 396 间空教室精准排查**、**课程直播点播直达当堂回放**及**多维学业成绩/排名证明生成**等核心功能。

全应用贯彻 Google Material Design 3 规范与 Edge-to-Edge 沉浸式设计，通过 Jetpack 硬件级加密技术与严格的安全防护体系，全方位保护同学们的个人账号与学业隐私。

## 🌟 核心功能特性

### 🎓 一网畅学 (TronClass) 原生深度集成
- **全量原生二级详情页**：
  - 彻底告别繁琐易卡的外部网页跳转，底栏常驻专属 Tab；
  - 课程详情涵盖四大原生子模块：**章节课件**（多媒体在线播放、PDF/Office 文档预览与附件离线高速下载）、**测验与考试**、**班级成员**及**课程公告**。
- **极速自动同步与进度追踪**：
  - 支持多课件并发无感同步已读与学习状态，实时计算课程总体进度百分比（如 `已完成 85% (74/87项)`）。
- **作业提交与交互体验重构**：
  - **附件双选支持**：新增快捷“拍照提交”与“选择文件”选项，作业附件管理简单直观；
  - **一键提取题目要求**：作业详情页顶栏右侧新增统一风格的快捷复制按钮，一键将教师发布的题目要求完整拷贝至剪贴板；
  - **软键盘与避让优化**：输入区域自适应软键盘平滑推起，支持多行附言格式保留提交与渲染，下拉刷新指示器避让毛玻璃悬浮顶栏；
  - **智能重提保障**：重新提交作业时底层自动合并“撤回旧作业”与“提交新版本”两步操作，单次点击即刻生效。
- **截止时间二级智能提醒系统 (DDL Guard)**：
  - **首轮预警（24小时前）** 与 **临期紧急提醒（临近1~3小时）** 独立开关与自主阈值配置；
  - 采用 `WorkManager` 后台周期同步与 `AlarmManager` 精准唤醒双重保障，深度休眠（Doze 模式）下精准触达，结合本地状态动态去重防骚扰。
- **原生高精度扫码签到**：
  - 依托 **Google ML Kit + CameraX** 打造的原生离线二维码极速扫描器（锁定竖屏，杜绝旋转异常）；
  - 支持 GPS 经纬度位置上报签到、数字口令签到与普通签到。

### 🧪 实验课表导入与自动修复引擎
- **多格式兼容导入**：
  - 课表页右上角支持一键导入选课预约文件，完美支持标准 `.xlsx` 工作簿，向下兼容 `.csv`、HTML 结构表格及扩展名为 `.xls` 的文本表。
- **内置全自动修复引擎**：
  - **自动剔除 UTF-8 BOM 标头**：修复系统导出非法字符导致的解析失败；
  - **XML 结构容错校验**：自动修正缺失 Sheet 索引或畸变节点；
  - **智能去重与时段折算**：按上理标准教学周与作息时间，自动将实验公历时间换算为周次、星期与节次；自动剔除空行并合并同一时段重复预约；
  - **零破坏纯本地运行**：仅在临时工作副本中运算，源文件哈希绝对不变；预约数据存入独立的 `lab_reservation` 表，与教务课表完全隔离。

## 🔒 深度安全与隐私保障体系

本项目全面通过安全合规复审，对网络、凭据、组件、存储实行全链路加固：

| 安全维度 | 加固措施与实现原理 |
| :--- | :--- |
| **凭据硬件级加密** | 教务账密与畅课凭据全面采用 Google Jetpack `EncryptedSharedPreferences` + Android Keystore (AES-256 SIV/GCM) 硬件级加密存储；冷启动自动无感迁移旧版明文数据并安全抹除；退出登录时全量清空所有凭据与离线缓存。 |
| **通信传输安全** | `network_security_config.xml` 默认全局禁用明文 HTTP (`cleartextTrafficPermitted="false"`)，同时针对校方部分历史教务系统与内网直录播服务器尚未部署 SSL/HTTPS 的客观情况，仅对 `*.usst.edu.cn` 校园受信域名保留必要的明文通信白名单例外；OkHttp 拦截器严格校验目标域名白名单，防范鉴权 Session 凭证外泄至第三方。 |
| **CAS SSO 严格校验** | 严格核验 HTTPS scheme、官方认证权威域名（`ids6.usst.edu.cn`、`ids6-443.webvpn.usst.edu.cn`）及 `/authserver/login` 路径前缀，彻底防御钓鱼页面劫持。 |
| **多账号防串染** | 进入畅课与教务前校验当前学号一致性，检测到账号切换自动刷新并重建离线缓存，防止多账号在同一设备使用产生数据串染。 |
| **WebView 安全沙箱** | 生产 Release 构建全局关闭远程调试 (`setWebContentsDebuggingEnabled=false`)；全面禁用混合内容。 |
| **存储暴露收窄** | `FileProvider` 路径严格收缩在私有下载（`Download/`、`downloads/`）、拍照暂存（`pending_uploads/`）与成绩报表（`grade_reports/`）等专有业务子目录，坚决杜绝根目录及全盘目录遍历暴露；禁用系统备份 (`allowBackup="false"`)。 |
| **纯净本地运行** | **本 App 为开源学习交流项目，不设任何收集个人信息的外部中心服务器，全部教务数据与凭据均在本地受保护存储区运行。** |

## 🛠️ 技术架构与选型

- **核心语言**：Kotlin 2.0+（全协程高并发异步架构）
- **目标平台**：Android 7.0+ (API Level 24 ~ 36)，专为 64 位平台优化（`arm64-v8a`）
- **UI 框架**：Material Design 3 (Material Components for Android) + ViewBinding + BlurView 动态毛玻璃
- **架构组件**：Jetpack Lifecycle (Runtime), WorkManager, AlarmManager, Material3 BottomSheet
- **网络通信**：Square OkHttp 4.12, Jsoup 1.17, Google Gson 2.10
- **安全加固**：AndroidX Security Crypto (Keystore AES-256 SIV/GCM)
- **视觉识别**：Google ML Kit Barcode Scanning + CameraX (1.3.4)
- **文档引擎**：Android 原生 PdfDocument 渲染引擎 + 自研 CID-CMap PDF 字符解码器
